Welcome to Cora

Cora records your meetings, transcribes and structures them, and separates speakers — 100% locally by default, using MLX Whisper and a local Liquid model on your own Mac. No account, no API key required.

  • Local transcription & summaries — nothing leaves your Mac unless you turn on the optional cloud coaching plugin later.
  • Auto meeting detection — Zoom, Google Meet, Teams, Slack Huddles.
  • Live notepad alongside the transcript and summary for every meeting.
  • Screenshot capture with local OCR so on-screen text is searchable too.
  • A personal memory — names, terms, and context Cora learns from your own meetings, improving transcription accuracy over time.

You'll be asked for Microphone, Screen Recording, and Accessibility access along the way — each one explained right before macOS asks, never as a surprise.
