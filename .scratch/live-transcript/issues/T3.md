# T3 Which transcript to show, Draft transcript, draft notes

Part of `docs/specs/live-transcript.md`. Read it, the ADRs it lists and `GLOSSARY.md` first.

## What to build
Recording API reports the transcript to show: live while recording, full when ready, Live as 'Draft transcript' + Retry when processing failed. Draft notes at stop from the Live transcript (small budget), replaced by full notes. Live file kept, follows retention, deleted with the Recording, never in Export, included in Captured Recordings.

## Done when
HTTP tests for the three states, draft-then-replace, export excludes live, delete removes it.
