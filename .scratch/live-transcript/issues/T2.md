# T2 Live transcript writer, captions, setting

Part of `docs/specs/live-transcript.md`. Read it, the ADRs it lists and `GLOSSARY.md` first.

## What to build
Parse LIVE lines in the helper parser; write one JSONL per Recording session (track, speaker hint from SPEAKER_ACTIVE, start, end, text, final, Chunk id, engine), continuing across Chunks. Captions in the floater and the Transcript tab while recording; 'Live captions paused' on failure/lag; remove the fake 'Transcribing…' feed. Processing profile `live` field (off / on_device / cloud_vertex), default off; Settings UI.

## Done when
JS tests with scripted lines: JSONL written in order with Chunk ids, captions update, paused notice, recording unaffected by bad/missing lines.
