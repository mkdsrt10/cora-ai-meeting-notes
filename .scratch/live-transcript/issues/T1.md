# T1 Helper: on-device live engine + WAV input mode

Part of `docs/specs/live-transcript.md`. Read it, the ADRs it lists and `GLOSSARY.md` first.

## What to build
In the Swift capture helper: per-track PCM tap (16 kHz mono); port from the Pace repo (`~/cora/cora-mac-jarvis`) Silero CoreML VAD chunks → WhisperKit on the Neural Engine → LocalAgreement stabilizer; Apple Speech fallback (restart per ~1 min), Apple's newer transcriber on macOS 26+ behind an availability check. Emit `LIVE_PARTIAL` / `LIVE_FINAL` (track, start, end, text). Add a WAV-file input mode for tests. Recording file path untouched. Measure English base vs a multilingual model.

## Done when
Fixture WAVs (fictional speech) → well-formed lines per track, monotonic times, stable text never retracted, fallback used when the model is missing; recording unchanged.
