# T2 Context assembler + People source, behind a setting

Part of `docs/specs/plugin-harness-local-proof.md`. Read it, the ADRs it lists and `GLOSSARY.md` first.

## What to build
Add optional `context_sources` / `proposer` / `connection` fields to `Plugin`. Build the `ContextSource` seam and `assemble(recording, section)`: per-section budgets (smaller for the local Provider), priority packing, dedupe, truncation marker, `<context source=…>` tags with the data-not-instructions line, 3 s deadline per source with cache fallback, `notes_context.json` manifest. First source: People (role/org of matched Participants). A setting turns context for notes on; default off (Q27).

## Done when
Notes-seam tests with `FakeText`: tagged blocks in each section's prompt within budget; local budget smaller; slow/erroring source skipped; manifest lists used and dropped; setting off = prompts unchanged. A test plugin adds a source with no core edits.
