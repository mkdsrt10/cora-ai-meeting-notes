# T6 Accounts on the Person page

Part of `docs/specs/plugin-harness-local-proof.md`. Read it, the ADRs it lists and `GLOSSARY.md` first.

## What to build
Person page shows a Notion row and a Slack row: suggested by name from the Connection's user list (names only), Confirm / Not them, then reused. Used for Notion Assignee and Slack mentions; unconfirmed = empty Assignee / plain name.

## Done when
HTTP tests: suggestion by name, confirm, not-them, reuse; unconfirmed behaviour.
