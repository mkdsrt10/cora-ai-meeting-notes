# T1 Core Action items as records

Part of `docs/specs/plugin-harness-local-proof.md`. Read it, the ADRs it lists and `GLOSSARY.md` first.

## What to build
Move the Action item store out of the To-dos plugin into a core module, keeping existing ids and done marks (one-time migration). Shape `{text, owner, due?, done, provenance}`; local notes extraction emits owner/due like the Gemini path. User-added/edited items are never superseded by reprocessing; AI items the user deleted stay deleted; rewording with ~0.8 token overlap keeps identity. To-dos becomes a View over core records, UI unchanged.

## Done when
Existing To-dos tests pass unchanged; new tests: ids and done marks survive migration and reprocessing, user edit wins, user delete sticks, reworded item keeps id.
