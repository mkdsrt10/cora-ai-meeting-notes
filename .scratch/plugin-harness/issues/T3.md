# T3 Prior meetings + Work context sources

Part of `docs/specs/plugin-harness-local-proof.md`. Read it, the ADRs it lists and `GLOSSARY.md` first.

## What to build
Prior meetings source: open Action items and recent decisions from meetings with the same People or folder. Work context: Settings › Profile "About my work" field, injected as `instructions`. ASR vocabulary context consumes `kind="terms"` blocks.

## Done when
Notes-seam tests for both sources; Profile field saved and read; terms blocks reach the ASR context.
