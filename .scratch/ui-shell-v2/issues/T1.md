# T1 Shell frame, tokens and the switch

Part of `docs/specs/ui-shell-v2.md`. Read it, ADR 0005 (and 0002, 0004), `GLOSSARY.md` and design doc §13.10 first. Visual reference: `git show fab55e9:src/ui/web/prototype-plugins-ux.html`.

## What to build
Second page served by the same server for the v2 shell, in its own folder. Prototype design tokens (light + dark) as its CSS base; dark mode follows macOS with a Light/Dark/System override. Stored setting `ui_shell: classic | v2` (default classic); Electron main loads the matching page; Settings › 'Try the new look' in classic and 'Back to the classic look' in v2. Empty sidebar + content frame, collapsible sidebar, focus rings.

## Done when
Renderer test: switch writes the setting and both pages load; the main process picks the page from the setting (JS test). Classic shell unchanged (existing tests pass). Lint clean.
