# T3 Sidebar, Home and ⌘K

Part of `docs/specs/ui-shell-v2.md`. Read it, ADR 0005 (and 0002, 0004), `GLOSSARY.md` and design doc §13.10 first. Visual reference: `git show fab55e9:src/ui/web/prototype-plugins-ux.html`.

## What to build
Sidebar: search, Home, Suggested (only when count > 0), People, plugin nav items from `app.nav`, Recent meetings, Folders, Settings. Home: meeting list with date, duration, people, status, processing progress/failures, all current filters (date, Folder, status, search), recording controls (start/stop/pause, active call). ⌘K command menu: pages, recent meetings, search, Cora actions for the current context, plugin `app.command`/`selection.action`/`recording.menu` contributions. Fixed Cora shortcuts.

## Done when
Fake-DOM tests: sidebar items by plugin state and count; Home filters; ⌘K lists Cora + plugin actions and runs the chosen one; no plugin-defined keys.
