# Code of Conduct

We want Cora to be a welcoming project for everyone. Participants in this project — in issues, pull
requests, discussions and any other project space — are expected to:

- be respectful and considerate, and assume good intent;
- give and accept constructive feedback gracefully;
- focus on what is best for the community and the project's users.

Not acceptable: harassment, personal attacks, discriminatory or sexualised language or imagery,
publishing others' private information (including meeting content) without consent, and other
conduct that would be inappropriate in a professional setting.

Maintainers may remove, edit or reject contributions that don't follow this code, and may
temporarily or permanently ban contributors for behaviour they deem harmful.

To report a problem, contact the maintainers privately via the repository's security reporting
channel (see [SECURITY.md](SECURITY.md)) or the maintainer's GitHub profile. Reports are handled
confidentially.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
